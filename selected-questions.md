# Отобранные вопросы для подготовки к ВИ

**Тема магистерской:** методика адаптивного контроля знаний на основе анализа развёрнутых ответов обучающихся.

**Критерий отбора:** по две дисциплины — по два вопроса из разных разделов, с максимальной связью к теме диссертации и разработке ПО. Все вопросы входят в 🔴-ядра соответствующих `thesis-priority.md`.

## Рекомендация по подготовке

1. Начать с **2.3.4** — здесь методика звучит наиболее убедительно для комиссии.
2. Параллельно готовить **2.3.5** — техническая реализация системы.
3. **2.3.6** — держать фокус на КИС/АСОД, не уходить в физическую защиту и помещения.
4. **2.2.15** — использовать только точечные аналогии, не «натягивать» ВОЛС и модуляцию на NLP.

**Источники ответов:** готовые конспекты есть в `study/2.3.5/notes/answers.md` и `study/2.3.4/notes/answers.md`; для 2.3.6 и 2.2.15 нужно составлять по программам и `thesis-priority.md`.
