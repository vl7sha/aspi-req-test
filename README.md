## Быстрый старт

1. Откройте [study-plan.md](study-plan.md) — план на 24 недели.
2. По каждой дисциплине: `study/<код>/thesis-priority.md` — приоритетные вопросы под вашу тему.
3. Отмечайте прогресс в [progress.md](progress.md).
4. Пишите конспекты в `study/<код>/notes/`.
5. Готовьте устные ответы в `mock-exams/`.

## Формат ВИ

- **Специальная дисциплина** — основной приоритет при ранжировании.
- **Иностранный язык** (английский, профессиональная сфера) — дополнительный экзамен.
