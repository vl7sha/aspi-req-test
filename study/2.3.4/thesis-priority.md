# 2.3.4 — вопросы по тематике диссертации

**Тема:** методика адаптивного контроля знаний на основе анализа развёрнутых ответов обучающихся.

**Всего в программе:** ~46 вопросов* → **изучать в первую очередь: 20**, затем 12, отложить: 14.  
**Готовые ответы:** [notes/answers.md](notes/answers.md) (часть тем объединена — см. пробелы в файле)

\* Уточнить у каф. ПИ официальный список билетов; нумерация — в [questions.md](questions.md).

> Это **главная дисциплина** для научной увязки диссертации с ВИ: здесь ваша тема — не «приложение к телекому», а предмет управления и ИИС.

## Сквозной сценарий для устного ответа

**Ключевая формулировка:**

> «Методика адаптивного контроля — это **СППР в образовательной организационной системе** (1.7, 1.8). Анализ развёрнутых ответов реализуется средствами **ИИС** (5.3–5.5): представление знаний предметной области (5.6), **Data Mining** и **нейросети** для обработки текста (5.10–5.11), при необходимости — **нечёткая логика** для частичных ответов (5.8). Результат анализа — **управленческое решение** (5.1, 1.9) о следующем задании. **Эффективность** методики оценивается по критериям управления (2.3).»
