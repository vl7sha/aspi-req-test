# Справка: пуассоновский процесс и распределение Эрланга

- **Дисциплина:** 2.2.15 — Системы, сети и устройства телекоммуникаций
- **Вопрос:** 1.7
- **Исходный материал:** [`Пуассоновский_процесс_и_распределение_Эрланга_1.docx`](../../Пуассоновский_процесс_и_распределение_Эрланга_1.docx)

> Пуассоновский процесс (поток событий). Распределение Пуассона и Эрланга. Распределение интервалов времени между событиями. Обобщённый пуассоновский процесс.

Формулы записаны обычным текстом, без LaTeX. Параметр `lambda > 0` везде понимается как интенсивность — среднее число событий в единицу времени.

Вопрос объединяет три разных случайных объекта:

| Объект | Что описывает | Распределение |
|---|---|---|

| `T_i` | время между соседними событиями | экспоненциальное |
| `S_k` | время от начала наблюдения до k-го события | Эрланга |

Кроме того, нужно:

1. определить свойства пуассоновского потока;
2. показать связь перечисленных распределений;
3. объяснить, что понимается под обобщённым пуассоновским процессом.

## 2. Пуассоновский процесс

Пусть `N(t)` — число событий, произошедших на интервале `(0, t]`.

**Однородный пуассоновский процесс** с интенсивностью `lambda` обладает следующими свойствами:

1. `N(0) = 0`;
2. `N(t)` принимает целые неотрицательные значения и не убывает;
3. приращения на непересекающихся интервалах независимы;
4. распределение приращения зависит только от длины интервала, то есть приращения стационарны;
5. поток ординарен: вероятность двух и более событий за бесконечно малый интервал имеет более высокий порядок малости, чем длина этого интервала.

Для любых `0 <= s < t`:

```text
N(t) - N(s) ~ Poisson(lambda * (t - s))
```

Иными словами:

```text
P{N(t) - N(s) = k} =
    exp[-lambda * (t - s)] *
    [lambda * (t - s)]^k / k!,

k = 0, 1, 2, ...
```

Локальная характеристика процесса при малом `h`:

```text
P{за время h не произойдёт событий} =
    1 - lambda*h + o(h)

P{за время h произойдёт одно событие} =
    lambda*h + o(h)

P{за время h произойдут два события или более} =
    o(h)
```

Последнее условие выражает ординарность потока.

Важно говорить о **стационарности приращений**, а не самого счётного процесса. Сам `N(t)` не стационарен, поскольку его среднее растёт со временем.

---

## 3. Распределение Пуассона

Число событий за интервал длины `t` имеет распределение Пуассона:

```text
P{N(t) = k} =
    exp(-lambda*t) * (lambda*t)^k / k!,

k = 0, 1, 2, ...
```

Его основные числовые характеристики:

```text
E[N(t)]   = lambda*t
Var[N(t)] = lambda*t
```

Параметр `lambda*t` одновременно равен математическому ожиданию и дисперсии числа событий.

Смысл параметров:

- `lambda` — среднее число событий в единицу времени;
- `t` — продолжительность наблюдения;
- `lambda*t` — среднее число событий за весь интервал.

---

## 4. Интервалы между событиями

Пусть моменты событий имеют вид:

```text
0 < tau_1 < tau_2 < ... < tau_k < ...
```

Времена между соседними событиями:

```text
T_1 = tau_1
T_i = tau_i - tau_(i-1), i >= 2
```

Для однородного пуассоновского процесса величины `T_i` независимы, одинаково распределены и имеют экспоненциальное распределение с параметром интенсивности `lambda`:

```text
T_i ~ Exp(rate = lambda)
```

Функция распределения:

```text
F_T(t) = P{T <= t} = 1 - exp(-lambda*t), t >= 0
```

Плотность:

```text
f_T(t) = lambda * exp(-lambda*t), t >= 0
```

Вероятность ожидания дольше `t`:

```text
P{T > t} = exp(-lambda*t)
```

Числовые характеристики:

```text
E[T]   = 1/lambda
Var[T] = 1/lambda^2
```

Экспоненциальное распределение обладает свойством отсутствия памяти:

```text
P{T > s + t | T > s} = P{T > t}
```

Если событие не произошло в течение времени `s`, оставшееся время ожидания распределено так же, как в начале наблюдения.

---

## 5. Распределение Эрланга

Время до наступления k-го события равно сумме первых k межприходных интервалов:

```text
S_k = T_1 + T_2 + ... + T_k = tau_k
```

Так как величины `T_i` независимы и имеют одинаковое экспоненциальное распределение, `S_k` имеет распределение Эрланга:

```text
S_k ~ Erlang(shape = k, rate = lambda)
```

Плотность распределения:

```text
f_Sk(t) =
    lambda^k * t^(k-1) * exp(-lambda*t) / (k-1)!,

t >= 0
```

Функция распределения:

```text
F_Sk(t) =
    1 - exp(-lambda*t) *
        sum от j=0 до k-1 [(lambda*t)^j / j!]
```

Числовые характеристики:

```text
E[S_k]   = k/lambda
Var[S_k] = k/lambda^2
```

Распределение Эрланга является частным случаем гамма-распределения:

```text
shape = k
rate  = lambda
scale = 1/lambda
```

При `k = 1` распределение Эрланга **совпадает с экспоненциальным**, а не становится вырожденным.

---

## 6. Связь распределений Пуассона и Эрланга

Событие «k-е событие произошло не позднее момента `t`» эквивалентно событию «к моменту `t` произошло не менее k событий»:

```text
{S_k <= t}  <=>  {N(t) >= k}
```

Поэтому:

```text
P{S_k <= t} = P{N(t) >= k}
```

Или, в дополнительной форме:

```text
P{S_k > t} = P{N(t) <= k - 1}
```

Это главная связь трёх частей вопроса:

- распределение Пуассона описывает **число событий за заданное время**;
- экспоненциальное распределение описывает **время между двумя соседними событиями**;
- распределение Эрланга описывает **время до заданного по номеру события**.

---

## 7. Сложный, или обобщённый, пуассоновский процесс

Термин «обобщённый пуассоновский процесс» используется неоднозначно. В исходном DOCX под ним понимается **сложный пуассоновский процесс**.

Пусть:

- `N(t)` — однородный пуассоновский процесс;
- `xi_1, xi_2, ...` — независимые одинаково распределённые случайные величины;
- последовательность `xi_i` не зависит от `N(t)`.

Тогда:

```text
Y(t) = xi_1 + xi_2 + ... + xi_N(t)
```

Если `N(t) = 0`, сумма принимается равной нулю.

Процесс `N(t)` определяет моменты скачков, а `xi_i` — их случайные величины. При существовании необходимых моментов:

```text
E[Y(t)] =
    lambda*t * E[xi]

Var[Y(t)] =
    lambda*t * E[xi^2]
```

Примеры:

- `N(t)` — число поступивших пакетов, `xi_i` — размер i-го пакета;
- `N(t)` — число заявок, `xi_i` — требуемый объём вычислений;
- `N(t)` — число страховых случаев, `xi_i` — величина выплаты.

Если каждый скачок равен единице, то есть `xi_i = 1`, сложный процесс совпадает с обычным счётчиком `N(t)`.

---

## 8. Неоднородный пуассоновский процесс

Неоднородный пуассоновский процесс — другое расширение базовой модели. Его интенсивность является детерминированной функцией времени:

```text
lambda = lambda(t) >= 0
```

Среднее число событий между моментами `s` и `t`:

```text
A(s, t) = integral от s до t функции lambda(u)
```

Тогда:

```text
N(t) - N(s) ~ Poisson(A(s, t))
```

То есть:

```text
P{N(t) - N(s) = k} =
    exp[-A(s, t)] * A(s, t)^k / k!
```

В отличие от однородного процесса:

- приращения остаются независимыми, но уже не стационарны;
- интервалы между событиями в общем случае не являются одинаково распределёнными величинами `Exp(lambda)`;
- модель позволяет описывать суточные колебания и пиковую нагрузку.

Неоднородный и сложный пуассоновские процессы не являются синонимами:

- в неоднородном процессе меняется интенсивность событий;
- в сложном процессе события имеют случайные величины скачков.

## 9. Применение к системе адаптивного контроля

В системе контроля знаний можно принять:

```text
N(t) =
    число ответов, поступивших за время t

lambda =
    средняя интенсивность поступления ответов

T_i =
    время между соседними поступившими ответами

S_k =
    время до поступления k-го ответа
```

Такая модель позволяет оценивать:

- ожидаемое число ответов за заданный интервал;
- вероятность поступления определённого количества ответов;
- время накопления пакета из `k` ответов;
- нагрузку на сервер анализа и очередь обработки.

Однако пуассоновская модель применима только как проверяемое приближение. Необходимо проверить:

- независимость поступлений;
- приблизительное постоянство интенсивности;
- отсутствие одновременных групповых отправок;
- соответствие дисперсии числа ответов его среднему.

Около дедлайна и во время экзамена интенсивность обычно меняется. В этом случае более реалистична модель `lambda(t)`. Синхронная отправка работ целой группой может нарушать и независимость, и ординарность потока.

## 11. Типичные ошибки

1. Называть `N(t)` стационарным процессом вместо процесса со стационарными приращениями.
2. Смешивать число событий `N(t)`, межприходное время `T_i` и время до k-го события `S_k`.
3. Не указывать, что `lambda` — интенсивность с размерностью «событий в единицу времени».
4. Забывать условие ординарности.
5. Называть распределение при `k = 1` вырожденным.
6. Считать сложный и неоднородный процессы одним и тем же.
7. Автоматически применять модель Пуассона к реальному потоку без проверки её предпосылок.
